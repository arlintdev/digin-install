1. Wait for it:
     kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ $fullname }}

2. Open {{ .Values.publicUrl }}
{{- if not .Values.ingress.enabled }}
   No Ingress was made: route that https address to the service {{ $fullname }}:{{ .Values.service.port }}.
{{- end }}
   Your sign-in provider must allow the redirect URL {{ .Values.publicUrl }}/auth/callback

3. Make the first administrator. Sign in once, then:
     kubectl -n {{ .Release.Namespace }} exec deploy/{{ $fullname }} -c digin -- digin org admin you@example.com

4. Enter a license key (Organisation > License in the app, or):
     kubectl -n {{ .Release.Namespace }} exec -i deploy/{{ $fullname }} -c digin -- digin license install - < license.txt

Check the deployment against Digin's secure baseline:
     kubectl -n {{ .Release.Namespace }} exec deploy/{{ $fullname }} -c digin -- digin check

across them; one server holds the calls at a time and hands them over when it stops. Each pod's name is
its DIGIN_INSTANCE. Which servers hear each other, and which holds the calls:
     kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=server -c digin | grep relay
   and on /metrics: digin_relay_peers, digin_calls_held (1 on one pod).
Updates roll one pod at a time with none down; a stopping pod drains for {{ .Values.shutdownDelaySeconds }}s first.
